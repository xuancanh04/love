# Security Policy

## Supported Versions

Các phiên bản hiện đang được duy trì và nhận các bản vá bảo mật:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Nếu bạn phát hiện bất kỳ vấn đề bảo mật nào trong dự án, vui lòng không mở công khai trên trang Issues của GitHub.

Thay vào đó, bạn hãy:
1. Gửi thông tin qua tính năng **Private Vulnerability Reporting** trên repository GitHub của dự án (nếu đã kích hoạt).
2. Hoặc liên hệ trực tiếp với tác giả qua GitHub profile: [@xuancanh04](https://github.com/xuancanh04).

Vui lòng cung cấp:
- Mô tả chi tiết về lỗ hổng hoặc hành vi bất thường.
- Các bước tái hiện (reproduction steps).
- Mức độ ảnh hưởng tiềm tàng.

Chúng tôi sẽ xem xét và phản hồi trong thời gian sớm nhất có thể.
