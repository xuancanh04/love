Một trang web tương tác ý nghĩa, ngọt ngào và lãng mạn dành tặng nửa kia nhân ngày **Phụ nữ Việt Nam 20/10**, được xây dựng với hiệu ứng hình ảnh 3D 360°, âm nhạc du dương, bức thư tay xúc động và bao lì xì bất ngờ.

---

## ✨ Điểm nổi bật & Tính năng (Features)

- 🎁 **Màn 1 - Mở hộp quà bí mật**: Hiệu ứng mở hộp quà hồi hộp với pháo hoa giấy rực rỡ.
- 💐 **Màn 2 - Bó hoa tương tác**: Chạm vào bó hoa để bung nở hình ảnh chân dung người thương được lồng ghép nghệ thuật.
- 🪐 **Màn 3 - Không gian 3D 360° đa tầng**:
  - Không gian ảnh kỷ niệm xoay vòng 3D mượt mà (60 FPS) hỗ trợ vuốt chạm cảm ứng hoặc kéo chuột.
  - Vô vàn lời chúc tình cảm tỏa sáng neon cùng tim đỏ bay lơ lửng.
  - Tùy chọn bật/tắt tự động xoay và bật/tắt nhạc nền lãng mạn.
- 💌 **Màn 4 - Phong bì sáp niêm phong & Thư viết tay**:
  - Mở phong bì cổ điển phong cách tem sáp.
  - Hiệu ứng đánh chữ (Typewriter) từng dòng tâm sự chân thành.
- 🧧 **Màn 5 - Lì xì bất ngờ**:
  - Bao lì xì đỏ rực mang lại niềm vui bất ngờ và nụ cười cho đối phương.

---

## 🛠️ Công nghệ sử dụng (Tech Stack)

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Library**: [React 19](https://react.dev/) & [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animation & Effects**: `canvas-confetti`, CSS 3D Transforms, Hardware Accelerated RequestAnimationFrame
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Hướng dẫn cài đặt và chạy thử (Getting Started)

### 1. Yêu cầu hệ thống
- [Node.js](https://nodejs.org/) phiên bản 18+ hoặc 20+
- npm, yarn, pnpm hoặc bun

### 2. Cài đặt các gói phụ thuộc

```bash
git clone https://github.com/xuancanh04/love.git
cd love
npm install
```

### 3. Chạy môi trường phát triển (Development)

```bash
npm run dev
```

Mở trình duyệt và truy cập: **[http://localhost:3000](http://localhost:3000)**

### 4. Build phiên bản phát hành (Production)

```bash
npm run build
npm run start
```
